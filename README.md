# Miram Ashraf — Web Developer Portfolio

## Run locally
Open `index.html` in your browser.

## Deploy on GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of a public GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The profile portrait is embedded in `index.html`, so no separate image file is required. Google Fonts requires an internet connection; the page otherwise uses system fallback fonts.
